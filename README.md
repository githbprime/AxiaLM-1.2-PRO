# AxiaLM 1.2 PRO
6.5 Million parameter agentic LLM trained on about 6.5 billion tokens of training data to be run in [Scratch](https://scratch.mit.edu) and/or [TurboWarp](https://turbowarp.org).

---

## How to set up

### Cloud
1. Open up your cloud environment (e.x. [Google Colab](https://colab.research.google.com), [Kaggle](https://Kaggle.com), [Runpod](https://Runpod.io), etc.)
2. Put the python script (`train.py`) into the cell
3. Allow internet access (*This is necessary so the script can import external databases from [Hugging Face](https://huggingface.co), you can also import the* HF token *to allow faster download speeds although not putting one worked fine for me*)
4. You **must** use an accelerator, training on a CPU is non-applicable.

### Python Environment
1. Open your python environment
2. Paste `train.py` into wherever your script goes
3. Make sure the environment can access the internet

| Note |
| - |
| Setting it up in the cloud and in a local environment are nearly identical, except the cloud runtime might have more steps to set up, or the other way around depending on what you use. |
